What TruthLens examines

Independent signals are shown separately so that weak clues are not mistaken for proof.

Vision classifier

A Hugging Face image-classification model provides a model-specific class score. Its reliability depends on its training data and evaluation scope.

Model inference

File metadata

Reads available EXIF and image-container metadata, including possible camera or generator hints. Metadata can be missing, edited or copied.

File inspection

Content credentials marker

Checks for C2PA/JUMBF-related markers. Marker detection is not the same as validating a signed manifest or its trust chain.

Marker only

Read the result responsibly

AI-image detection is an imperfect classification task. A score is not a probability of truth, and no single detector can establish provenance.

Important limitations

  • New image generators and out-of-domain content may not resemble the model's training data.
  • Resizing, cropping, screenshots, editing and social-media recompression can change model behavior.
  • Camera metadata is not proof of authenticity; it can be removed or forged.
  • This prototype does not cryptographically validate C2PA manifests.
  • Do not use this result alone for legal, journalistic, employment or other high-impact decisions.
